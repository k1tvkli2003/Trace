## Product truth and constraints

- Personal local-first workspace. The current implementation can import and read originals; AI/Vision/review/sync are not connected.
- Same shell must carry collection, source, worktree (when real), teaching, provenance, and review. Never mark a mock lesson as an extracted source.
- English LTR chrome; Persian RTL lesson independently; ASCII numerals; font pairing Inter/Vazirmatn. Responsive desktop/tablet/mobile and 200% text.

## Selection rubric

Score 0–5 each: primary task clarity, source trust/ethical state labeling, compositional distinction, 3-size transform, typography/bidi robustness, engineering cost, applicability to future worktree/review. Choose strongest coherent **system**, not single beautiful image. Repair generated text and fake claims in live Flutter; no preview raster is shipped as app chrome. Preserve existing import, source reading, draft confirmation, disabled send, local persistence, and selected app icon.
